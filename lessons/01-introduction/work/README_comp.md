## A. Разделитель CSV
При чтении reading_example.csv с sep=";" pandas не нашёл в строках ;, поэтому вся строка стала одним полем: wrong_sep.shape = (6, 1) вместо example.shape = (6, 7). В wrong_sep одна «склеенная» колонка, а не семь полей. Правильный разделитель этого файла - запятая (sep=",", значение по умолчанию)
## B. Частичное чтение
preview = read_csv(..., nrows=3) - shape (3, 7): только первые 3 строки, все столбцы. small_columns = read_csv(..., usecols=["action_taken", "income"]) - shape (6, 2): все 6 строк, только 2 столбца. nrows ограничивает строки при чтении (остальные не читаются), usecols - столбцы. nrows=3 не читает остальные строки вовсе, а head(3) показывает первые 3 строки уже полностью загруженной таблицы.

## D. Маленький пример

Одобрения action_taken в [1, 2], дробь n_approved_small / 6. Выдачи: условие action_taken == 1, дробь n_issued / 6. Сверка по шести исходам вручную совпадает с расчётом isin/eq + sum(). Обе доли лежат в [0, 1], проценты — умножение на 100.

## F. Проверки
таблица непустая, исходы только 1–3, пропуски income посчитаны через isna().sum(); full_approved + full_denied == full_n; 0 ≤ full_issued ≤ full_approved ≤ full_n; обе доли в [0, 1]. Эти assert ловят: не тот столбец исходов, не те коды, пропуски в исходах, перепутанные числители, доли вне диапазона. Пропущенный доход для расчёта долей не нужен: доли считаются по action_taken и full_n, а не по доходу; набор записей не меняем — пропуски дохода не исключаем.
Готовая ячейка называлась approval_rate («доля одобрений»), но условие eq(1) выбирало только выдачи — название не соответствовало расчёту. Исправление 1: название оставили, условие заменили на isin([1, 2]) - теперь approval_rate действительно доля одобрений. Исправление 2: условие eq(1) оставили, переменную переименовали в origination_rate - теперь название честно отражает долю выдач. Произвольно давать результату любое название нельзя: название фиксирует определение показателя (что в числителе), иначе отчёт вводит в заблуждение.
## Вывод
По 6 830 опубликованным записям о покупке жилья в Вашингтоне за 2023 год одобрения составляют около 89,9%, а выдачи  - около 79,8% всех заявок. Разница между этими долями - это одобрения без принятия предложения , примерно 10,1% записей. Ответ относится именно к этому набору: покупка жилья, Вашингтон, 2023 год; на другие годы, территории и типы кредитов его переносить нельзя. Пропуски дохода на расчёт долей не влияют, так как показатели считаются по исходу заявки и общему числу записей.
